# React Native Engineering Skill
When building React Native apps:
- Create `App.tsx` or `App.js` with modern React Native components (`View`, `Text`, `StyleSheet`, `TouchableOpacity`, `ScrollView`, `SafeAreaView`).
- Create `package.json` with required dependencies (`react`, `react-native`, `expo`).
- Include responsive styles using `StyleSheet.create({ ... })`.
- Provide web preview fallback in `index.html`.
